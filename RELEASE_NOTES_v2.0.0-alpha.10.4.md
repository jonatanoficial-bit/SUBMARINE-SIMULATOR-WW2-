# Release Notes — v2.0.0-alpha.10.4

Phase 10.4 homologates the simulation core before campaign expansion.

## New
- Cadet, Officer, Simulator and Hardcore difficulty profiles.
- Nine-step operational qualification based on actual simulator actions.
- Contextual guidance for all seven stations.
- Automatic danger-station recommendation.
- Progressive propulsion inertia.

## Difficulty effects
Profiles modify enemy detection, incoming damage, sensor assistance, TDC quality, historical torpedo failure probability and resource consumption. They do not bypass depth, noise, firing arc, reload, damage-control or safe-disengagement rules.

## Validation
The phase passed 522 structural checks, 110 unit tests, 111 browser checks, 52 difficulty patrol scenarios and telemetry for all 13 missions.
