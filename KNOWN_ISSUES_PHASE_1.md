# Problemas conhecidos — Fase 1

Itens intencionalmente deixados para as fases seguintes:

- gameplay ainda é um protótipo arcade, sem motor naval real;
- mobile exige rolagem extensa em várias telas;
- layout de tablet/PC ainda utiliza coluna estreita;
- orientação do PWA permanece prioritariamente retrato nesta fase;
- atributos de tripulação, upgrades e submarinos ainda não alimentam toda a simulação;
- campanhas das nações ainda não são historicamente independentes;
- gráficos, áudio, acessibilidade e controles ainda não atingem padrão comercial AAA;
- o smoke test visual do ambiente de geração usa um harness offline porque a política administrativa do Chromium bloqueia navegação por HTTP local; service worker é validado estaticamente nesta fase.
