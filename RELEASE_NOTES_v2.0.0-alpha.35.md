# Release Notes — v2.0.0-alpha.35 — Fase 20

Fase 20 adiciona reputação operacional e medalhas de campanha para Alemanha, Reino Unido e Estados Unidos. Cada nação possui cinco condecorações progressivas ligadas a missões concluídas, tonelagem, reputação, prestígio, operações especiais, etapas de cadeia e desfechos estratégicos. As honras concedem recompensas permanentes, modificadores de teatro, registro no diário, exportação no dossiê e migração segura para schema 14.
