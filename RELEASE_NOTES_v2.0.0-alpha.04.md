# Release Notes — v2.0.0-alpha.04

## Phase 4: Transactional Profiles, Save Recovery & Operation Autosave

This build introduces three independent commander profiles and a save schema designed to recover from corruption or interrupted writes.

### New

- Three local campaign slots.
- Active-profile summary on the main menu.
- Profile manager for activation, creation, deletion, export, import and backup restoration.
- Transaction journal, verified temporary record and automatic rollback.
- Three rotating backups per profile.
- One-time migration and archive of Phase 1–3 saves.
- Checksum-protected external save archive.
- Tactical operation autosave and mission resumption.
- Deterministic engine snapshot restoration.
- Portuguese, English and Spanish interface for every new workflow.

### Preserved

- Phase 1 security baseline and runtime safe mode.
- Phase 2 mobile-first responsive shell and immersive mode.
- Phase 3 deterministic simulation engine, scenes and entities.
- Existing campaign, arsenal, crew and combat flow.
