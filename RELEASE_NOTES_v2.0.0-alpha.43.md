# Release Notes — v2.0.0-alpha.43 — Fase 28

## Fase 28 — Ataque Aéreo e Evasão / Operação Silent Depth

Esta fase adiciona uma camada visual e tática para aeronaves ASW no gameplay, com painel mobile-first, radar aéreo, marcador de aeronave, recomendação de evasão e botões de decisão rápida.

## Principais entregas

- Novo sistema `airAttackEvasion`.
- Painel `phase28-air-attack-panel` no gameplay.
- Botões grandes: MERGULHAR, SILÊNCIO TOTAL e MANTER CURSO.
- Cálculo de perigo aéreo usando aeronave ativa, fixação, profundidade, periscópio, radar, ruído e clima.
- Integração com suboficial e alerta atmosférico.
- PWA/cache e smoke test atualizados.
