# Known Issues — Phase 5

No release-blocking issue is known.

Non-blocking scope limits:

1. The chart uses a procedural grid, not a coastline or bathymetric dataset yet.
2. Time compression accelerates operational navigation; tactical combat continues on the fixed real-time safety loop.
3. Waypoints are stored per operation autosave, not as reusable route templates across missions.
4. Patrol-sector entry is an additional objective and does not yet gate target contact or mission completion.
5. Keyboard navigation is provided for PC, while touch controls remain the primary mobile method.
