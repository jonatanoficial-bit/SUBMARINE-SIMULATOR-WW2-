# Submarine Commander WW2 — v2.0.0-alpha.42

## Fase 27 — Sistema de Alertas e Atmosfera / Operação Silent Depth

Esta fase adiciona uma camada cinematográfica de alerta para tornar o submarino mais vivo e menos técnico no mobile e no PC.

### Novidades

- Novo sistema `alertAtmosphere.js` com cinco estados: calmo, suspeita, evasão, combate e emergência.
- Novo painel visual de alerta na tela de gameplay.
- Barra de lâmpadas de estado com cores operacionais.
- Escore de ameaça calculado por detecção, pressão, casco, oxigênio, bateria, velocidade, contatos, escolta, torpedo e aeronaves.
- Alteração visual da cabine por estado de alerta.
- HUD de alerta colorido por nível de perigo.
- Pulso vermelho e vibração visual em combate/emergência.
- Integração com o sistema do suboficial e sala de comando Silent Depth.

### Compatibilidade

- Preserva F24 Periscópio Mobile Imersivo.
- Preserva F25 Sala de Comando Imersiva.
- Preserva F26 Suboficial/Copiloto Imersivo.
- Save schema atualizado para 21.
