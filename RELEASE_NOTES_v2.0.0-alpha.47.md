# Release Notes — v2.0.0-alpha.47

## Fase 32 — Rework de Ataque Torpédico / Diretor de Tiro

Esta versão adiciona um fluxo visual de ataque torpédico para aproximar o jogo da sensação de simulador naval: aquisição de alvo, triângulo de ataque, solução de tiro, recomendação do oficial de armas e feedback de corrida do torpedo.

Preserva integralmente as fases anteriores da Operação Silent Depth.
