# Release Notes — v2.0.0-alpha.28

## Fase 13 — Objetivos históricos de campanha
Esta versão aprofunda as campanhas independentes com metas históricas progressivas por nação, recompensas de ato, efeitos estratégicos e proteção anti-duplicação no save.

Sistemas anteriores preservados: campanhas independentes, doutrinas nacionais, logística, carreira, comando estratégico, ponte, periscópio, TDC, rolagem mobile, trilha sonora, clima/oceano, tripulação e IA de comboios/escoltas.
