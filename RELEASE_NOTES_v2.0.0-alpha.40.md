# Release Notes — v2.0.0-alpha.40

## Fase 25 — Sala de Comando Imersiva / Operação Silent Depth

Esta fase aprofunda a transformação visual iniciada no periscópio mobile e leva a experiência para dentro do submarino. A tela de ponte passa a ter uma cabine mais cinematográfica, com estrutura metálica, iluminação naval dinâmica e leitura visual do estado operacional.

### Destaques

- Novo sistema de ambiência da sala de comando.
- Moldura de cabine, tubos, válvula, anteparas e camadas de condensação.
- Silhuetas da tripulação em vigília.
- Painéis de estações com LEDs de severidade.
- Quadro visual de ameaça e estado do ambiente.
- Integração mobile/PC sem remover o HUD técnico existente.

### Compatibilidade

- Save schema: 19.
- PWA/cache atualizado para 2.0.0-alpha.40.
- Sistemas anteriores preservados.
