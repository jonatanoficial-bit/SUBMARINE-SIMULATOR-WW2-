# Fase 49 — Cadeia Reativa de Comando do Capitão

Build: v2.0.0-alpha.64

A Fase 49 aprofunda a gameplay de capitão. O jogador recebe a situação, escolhe a ordem e acompanha a resposta da tripulação. O suboficial pergunta e recomenda, o mecânico prioriza avarias, armas/TDC exigem solução e periscópio exige confirmação visual antes do disparo.

Validações planejadas: npm test, npm run smoke, npm run audit.
