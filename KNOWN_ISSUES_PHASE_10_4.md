# Known Issues — Phase 10.4

- Physical-device validation is still required for vendor-specific fullscreen, vibration, audio latency and PWA installation behavior.
- The operational qualification is contextual and state-driven; a future dedicated training mission can add scripted instructor voice-over.
- Difficulty changes apply when starting a new mission. A tactical autosave retains the profile with which it was created for deterministic recovery.
- Visual assets remain largely 2D; later presentation phases are still required for a fully commercial AAA-style cockpit and animation standard.
